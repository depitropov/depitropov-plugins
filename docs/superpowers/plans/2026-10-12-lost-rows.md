### Task 1: The no-result limit

**Files:**
- Modify: `plugins/orc-standard-workflow/bin/next.js` (`stage()`)
- Modify: `plugins/orchestra/lib/runner.js` (`agentStep`, `toolStep` fixer path)
- Test: `test/orc-standard-workflow/next.test.js`, `test/orchestra/runner.test.js`

The mechanism is the same in both files. Each file already has its own `readResult` and `reportOnce`; add the helper next to them in each file, as they do.

```js
// A subagent that writes no result is dispatched once more. Then the step fails (S69).
function noResult(file, name) {
  const sent = `${file}.sent`;
  const count = fs.existsSync(sent) ? Number(fs.readFileSync(sent, 'utf8')) : 0;
  if (count < 2) {
    fs.writeFileSync(sent, String(count + 1));
    return null;
  }
  fs.rmSync(sent);
  const res = { status: 'failed', reason: `${name} wrote no result after 2 dispatches.`, reported: true };
  fs.writeFileSync(file, JSON.stringify(res, null, 2) + '\n');
  return res;
}
```

- `next.js` `stage()`: in `if (!res)`, call `noResult(file, \`Stage ${name}\`)` first; if it returns a result, return `{ action: 'failed', reason, runDir }`. In the `retry` branch, also remove `${file}.sent` if it exists.
- `runner.js` `agentStep`: `if (!res)` calls `noResult` before `send()`; on a result, return `{ status: 'failed', reason }`. Where a gate's result is removed for a retry, also remove its `.sent` file.
- `runner.js` `toolStep`: `if (!fix)` calls `noResult` on the fix result file before `fixerDispatch`; on a result, go on to the existing `fix.status === 'failed'` line. `retryTool` removes files with the prefix; extend its filter to `.sent` files.

`reported: true` makes the first call stop with `failed`. The next call is a resume: the existing retry path deletes the result, and the step gets two fresh dispatches.

- [ ] **Step 2:** Run `node --test test/` and see the new tests fail.
- [ ] **Step 3:** Implement as above.
- [ ] **Step 4:** Run `node --test test/`; all pass.
